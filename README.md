# Gift Suggestion Web Service

**http://giftsuggestion.ru/**

## О проекте

Сервис помогает подобрать подарок для конкретного человека: пользователь указывает повод, бюджет, отношения, возраст и интересы — система предлагает подходящие варианты из каталога.

Каталог собирается из внешних источников (маркетплейсы) и хранится в базе с предложениями из разных магазинов. Рекомендации ранжирует ML-модель; если модель недоступна, используется запасной алгоритм на бэкенде.

Пользователь может просматривать каталог, сохранять понравившиеся подарки в список желаний, вести профиль и при желании подключить VK — тогда интересы подтягиваются из групп пользователя и учитываются при подборе.

## Стек

Монорепозиторий из трёх сервисов:

| Сервис | Стек | Путь |
|--------|------|------|
| **backend** | Go, Gin, PostgreSQL | `services/backend/` |
| **frontend** | React, Vite, TypeScript | `services/frontend/` |
| **ml-service** | Python, FastAPI, gRPC | `services/ml/` |

## Возможности

- Каталог подарков с фильтрами и карточками товаров
- Мастер рекомендаций с учётом повода, бюджета и интересов
- Список желаний (wishlist)
- Регистрация, авторизация, профиль
- Импорт каталога (админ)
- Интеграция с VK для синхронизации интересов
- ML-ранжирование рекомендаций (с fallback без модели)

## Структура репозитория

```
.
├── docker-compose.yml          # локальный запуск: postgres, backend, ml, frontend
├── deploy/                     # продакшен-деплой (HTTPS, Caddy, env-шаблоны)
├── scripts/
│   ├── ci/                     # скрипты проверок для GitHub Actions
│   └── data/                   # выгрузка, нормализация и импорт каталога
└── services/
    ├── backend/
    │   ├── cmd/                # точка входа API
    │   ├── internal/           # модули: auth, catalog, recommendation, VK и др.
    │   ├── migrations/         # схема PostgreSQL
    │   └── docs/openapi/       # контракт REST API
    ├── frontend/
    │   └── src/                # страницы, фичи, UI-компоненты
    └── ml/
        ├── ml_service/         # gRPC-ранжирование и health
        ├── training/           # подготовка данных и обучение модели
        ├── dataset/            # датасеты каталога
        └── models/             # обученные модели
```

## Быстрый запуск

Требования: Docker и Docker Compose.

```bash
docker compose up --build
```

После запуска: фронт — `http://localhost`, API — `http://localhost/api/v1/`.
